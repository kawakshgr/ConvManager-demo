# ConvManager (démo)

Prototype de ConvManager, la plateforme de gestion des conventions de tatouage. Ce dépôt contient uniquement la démo HTML de test, sans serveur ni base de données.

Trois pages, à ouvrir côte à côte (elles se renvoient les unes aux autres) :

- `index.html` : l'application des artistes, des organisateurs et des visiteurs
- `console.html` : la console de gestion des conventions, des bundles et de la facturation
- `connexion.html` : la page de connexion et d'invitation
